춤 관절 정보 만들기

춤 영상 목록을 넣으면, 영상마다 춤추는 한 사람의 3D 관절 움직임을 파일로 만듭니다.

1. 「춤 관절 정보 시작」(joints_control.py start --open)을 실행합니다. (주소: http://127.0.0.1:7864)
2. 「영상 목록」 칸에 한 줄에 영상 하나씩, 제목을 쓰고 끝에 유튜브 링크를 씁니다.
     NEON https://youtube.com/shorts/VIDEO_ID_1
     L을가져가 https://youtube.com/shorts/VIDEO_ID_2
   - 제목을 비우면 유튜브 제목을 씁니다. 링크 대신 이 컴퓨터의 영상 파일 경로를 써도 됩니다.
   - 영상마다 화면에 크게 나오는 한 사람의 춤을 뽑습니다.
3. 「전체 실행」을 누릅니다. 끝날 때까지 손댈 것이 없습니다.
   - 30초 쇼츠 하나에 3~4분 걸립니다(15개, 6분 44초 분량에 약 50분).
   - 영상은 하나씩 끝나는 대로 결과 폴더에 먼저 들어갑니다.
   - 중간에 멈췄으면 「멈춘 작업 이어서 하기」를 누르면 끝난 영상은 그대로 두고 나머지만 만듭니다.

결과는 결과 폴더(설정 results_dir) 안에 작업마다 새 폴더로 저장됩니다.
  결과_안내.txt   영상마다 무엇이 나왔는지와 알아 둘 것
  파일_설명.txt   results.npz, motion.bvh, motion_amass.npz의 형식과 관절 목록
  01_제목/ ...    영상마다 관절 파일과 관절_정면과_옆.mp4
  관절_파일_모음.zip   위의 관절 파일과 안내 글을 하나로 묶은 것(원본 영상이 보이는 것은 없음). 다른 컴퓨터로 옮길 때 씁니다.
  검증용_원본포함_공유금지/   원본 영상 위에 관절을 그린 확인 영상. 밖으로 내보내지 마세요.

다른 컴퓨터에서 묶음 파일 가져오기 (그 컴퓨터의 명령 창에서):
  scp "<사용자>@<이 컴퓨터 주소>:<결과 폴더>/작업폴더이름/관절_파일_모음.zip" .

화면 없이 명령으로 실행:
  python3 -B programs/dance-joints/dance_joints.py --list 목록.txt
  (옵션: --mirror keep  거울모드 영상도 화면 그대로 / --mirror flip  모두 좌우를 되돌림 / --job 작업폴더  이어서 하기)

화면 끄기: 「춤 관절 정보 중지」(joints_control.py stop).

프로그램이 스스로 하는 것
- 내려받기, 화면에 크게 나오는 한 사람을 끝까지 따라가기, 3D 동작 뽑기
- 화면에 보이는 바닥을 기준으로 몸을 바로 세우기(카메라가 기울어 찍혀도 몸이 기울지 않게). 사람이 그 바닥을 실제로
  디디고 있지 않으면(합성한 배경 등) 바닥을 쓰지 않음
- 편집으로 장면이나 배경이 바뀌는 곳을 카메라가 돈 것으로 읽지 않고, 춤추는 사람의 방향과 자리가 이어지게 하기
- 동작 추정이 뭉갠 빠른 움직임 되살리기
- 다리가 화면 밖인 장면(셀카 등)은 다리와 골반 높이를 앞뒤 장면에서 이어 붙이고 표시하기
- 사람이 안 보이는 장면은 앞뒤를 이어 추정하고 표시하기
- 거울모드 영상(제목에 "거울모드", "mirror mode", "mirrored" 등)은 좌우를 되돌려 실제로 춘 방향으로 뽑기
- 실패한 영상은 까닭을 적고 다음 영상으로 넘어가기

알아 둘 점
- 화면에 나오지 않은 몸(화면 밖의 다리, 가려진 팔)은 추정입니다. 어느 구간인지 결과_안내.txt에 적힙니다.
- 사람이 여럿이면 가장 크게 나오는 사람 하나만 뽑습니다.
- 제목에 적혀 있지 않은 거울 영상(휴대폰 앞 카메라로 찍어 뒤집힌 영상 등)은 알아내지 못합니다.
